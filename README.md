# GRAM

GRAM — локально запускаемая социальная сеть и мессенджер с публичной лентой, личными чатами, выразительными профилями, коллекционными юзернеймами, подарками и внутренней экономикой Stars.

## Быстрый запуск

Нужен Docker Desktop с Docker Compose.

```powershell
docker compose up --build -d
```

После запуска:

- приложение: http://localhost:3000
- API и OpenAPI: http://localhost:8000/docs
- healthcheck API: http://localhost:8000/health

Демо-аккаунт:

- логин: `leon` или `leon@gram.local`
- пароль: `GramDemo!2026`

Остановка без удаления данных:

```powershell
docker compose down
```

PostgreSQL и загруженные медиа сохраняются в Docker volumes. Не используйте `docker compose down -v`, если хотите сохранить локальные аккаунты, сообщения и коллекции.

## Что работает

- регистрация, onboarding, вход, refresh-сессия и выход через HttpOnly cookies;
- Argon2-хеширование паролей, отзыв и ротация refresh-сессий;
- загрузка аватара и обложки PNG/JPG/WEBP до 5 МБ;
- лента «Для вас», подписки и темы, публикации, лайки, комментарии, репосты и закладки;
- подписки на пользователей, рекомендации и платная подписка на автора;
- личные чаты, сохранённая история и WebSocket-доставка сообщений;
- публичные профили, проверка личности, связанные юзернеймы и приватные заметки о людях;
- сообщества: создание, вступление, выход и публикации;
- Stars: баланс, журнал операций, перевод и поддержка авторов;
- покупка Stars за Telegram Stars через собственного бота: заказ на сайте, счёт в боте, зачисление по отчёту о платеже;
- Creator Studio: цена подписки, настройки и аналитика;
- коллекционные юзернеймы: резерв, история владения, листинг и покупка за Stars;
- коллекционные подарки: выпуск, редкость, свойства, ценность, provenance, офферы и передача;
- установка собственного подарка в шапку профиля и компактного знака возле имени;
- уведомления с чтением одного события или всех событий;
- адаптивная мобильная навигация, компактный desktop rail и широкий трёхколоночный режим.

Функции эфиров в продукте нет. Голосовые/видеозвонки, вложения в чат и восстановление пароля помечены как «скоро» и не имитируют рабочие действия.

## Локальные границы

Stars, покупки, редкость, история владения и передача подарков работают в локальной PostgreSQL. Это самостоятельная коллекционная система GRAM, не официальный Telegram, не TON и не блокчейн-минтинг. Платежи идут только через Telegram Stars в собственном боте — карты и внешние провайдеры не подключены. Production-модерация, внешнее object storage и email-доставка пока тоже нет.


```powershell

.venv\Scripts\python -m ruff check app tests

```

## Структура

- `web/` — Next.js, React, TypeScript, Tailwind CSS, Framer Motion, Radix UI, Zustand, TanStack Query, React Hook Form и Zod.
- `api/` — Python 3.14, FastAPI, SQLAlchemy 2 и PostgreSQL.
- `bot/` — платёжный бот Telegram: счёт в Telegram Stars и отчёт о платеже в API.
- `compose.yaml` — локальный запуск web, API и PostgreSQL; бот — под профилем `bot`.
- `PRODUCT.md` — продуктовые принципы и границы.
- `DESIGN.md` — визуальная система, responsive-правила и компоненты интерфейса.
